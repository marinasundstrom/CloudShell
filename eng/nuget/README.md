# CloudShell

This package is part of CloudShell, an extensible, self-hosted control plane
for modeling, running, inspecting, and operating distributed applications in
local-development and team-owned environments.

CloudShell is currently an early preview. Its public APIs, package structure,
resource model, and hosting conventions can change between preview releases.
The current packages target .NET 11 preview.
